How it works

1. Start a sketch

npm run sketch -- my-idea
npm run sketch -- pdp-test --from product

Copies a starter into sketches/<name>/index.html and prints its URL.

2. Edit and save

Saving HTML reloads the page. Saving CSS swaps the styles in place, so you keep your scroll position and panel settings.

3. Copy values out

In the Design panel, press Copy CSS to copy only the tokens you changed, as a :root block.
