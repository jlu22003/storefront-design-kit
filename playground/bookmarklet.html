Design panel for any site

A bookmarklet that opens a design panel on top of the page you are looking at, so you can drag spacing, type, corners, and colors on a real site and copy out the values you like.

Install

  1. Show your browser's bookmarks bar.
  2. Drag this button onto it:
SDK Design

Building…


    

      Can't drag? Press Copy bookmarklet URL, add any bookmark, edit it, and paste
      the copied text as its URL. From a terminal, npm run bookmarklet writes the same URL
      to dist/bookmarklet.txt. Rebuild after updating the kit to get the latest panel.
    

  


  

    
Use

    
Open any site, then click SDK Design in your bookmarks bar. Click it again to hide or show the panel.

    
    
      
  • 
        Site variables. When the site defines CSS custom properties on
        :root, the panel sorts them into spacing, type, and radius sliders
        and color pickers. Shopify themes that store colors as 18, 18, 18
        get the same format back.
      
    • 
      
  • 
        Page overrides. Body text size, line height, container spacing
        (padding and gaps of sections, headers, footers, and containers), corner radius,
        and text, background, accent, and text-on-accent colors. These work on any site.
      
    • 
      
  • Contrast shows WCAG ratios for text and accent as you pick colors.
    • 
      
  • 
        Copy CSS copies only what you changed: a :root block for
        variables, then plain rules for the overrides.
      
    • 
    

  


  

    
What it does to the site

    
    
      
  • Changes only this tab, until you press Remove or reload. Nothing is saved: no storage, no cookies.
    • 
      
  • Sends nothing anywhere. The panel's code and styles are inside the bookmark, and it makes no network requests.
    • 
      
  • Adds one stylesheet and marks the containers it scales with a data-sdk-live-box attribute; Remove takes both away.
    • 
    

  


  

    
Limits

    
    
      
  • Some sites block bookmarklets with a strict Content Security Policy; the click then does nothing.
    • 
      
  • Variables redefined on inner elements (per-section color schemes, for example) keep their own values. Use the page overrides for those.
    • 
      
  • Only :root variables in readable stylesheets or the computed style are found; stylesheets from other domains cannot be scanned.
    • 
      
  • Container spacing is measured when you first move that slider; the copied rules name each container by id or tag and classes, are fixed px for the window width you measured at, and leave out any name whose containers differ.
