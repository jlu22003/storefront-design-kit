## Fonts

All three families are licensed under the SIL Open Font License 1.1 (OFL-1.1)
and are available in Shopify's font library, so Shopify themes load them from
Shopify's CDN. Non-Shopify sites self-host them with `OFL.txt` kept beside the
font files. Font files are not committed to this repository.

| Family | Role | License | Source |
|---|---|---|---|
| Inter | UI and body text | OFL-1.1 | https://github.com/rsms/inter/blob/master/LICENSE.txt |
| Source Serif 4 | Optional editorial headings | OFL-1.1 | https://github.com/adobe-fonts/source-serif/blob/release/LICENSE.md |
| IBM Plex Mono | Code and numbers | OFL-1.1, Reserved Font Name "Plex" | https://github.com/IBM/plex/blob/master/LICENSE.txt |

IBM Plex carries the Reserved Font Name "Plex": a modified or subset copy that
is redistributed must not use that name.
